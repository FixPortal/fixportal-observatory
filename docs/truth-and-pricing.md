# Truth and pricing

> Meaning and pricing-provenance guide for maintainers as of 2026-08-25. Token values are counts; stored catalog estimates and notional values are USD unless a Google billed export retains native currency.

An observation is not just a number. Its source, scope, cost basis, occurrence time, and observation time explain what it can honestly support. No missing value becomes zero.

## Truth labels

API wire values are camel-cased strings; provider and source IDs are open strings so a new source does not require a wire-schema change.

| Enum | Meaning |
| --- | --- |
| `SourceKind.ProviderApi` | A provider-operated usage, cost, or reporting API. |
| `SourceKind.LocalTelemetry` | Locally observed CLI, session, or transcript data. |
| `SourceKind.Manual` | A user-entered observation. |
| `SourceKind.Synthetic` | Demonstration data generated by Observatory, never evidence from a provider or local tool. |
| `SourceKind.Legacy` | Retained data whose original source cannot be recovered safely. |
| `UsageScope.Api` | Pay-as-you-go or contracted API consumption. |
| `UsageScope.Subscription` | Consumer/team coding-product allowance or activity. |
| `UsageScope.Mixed` | An upstream source explicitly combines scopes. |
| `UsageScope.Unknown` | The scope cannot be established. |
| `CostBasis.Billed` | Provider-reported financial cost or ledger evidence. |
| `CostBasis.ProviderEstimated` | A provider-produced estimate, not yet an invoice. |
| `CostBasis.ListPriceEstimate` | Tokens rated against an observed public catalog. |
| `CostBasis.Notional` | An API-list-price comparison for subscription/local activity where no money changed hands. |
| `CostBasis.None` | Usage is reported but no price applies. |
| `CostBasis.Unknown` | Legacy or insufficiently described cost. |

Events are source-scoped: `SourceId + EventKey` identifies one correctable snapshot. A duplicate canonical snapshot is a no-op; a changed one replaces its previous aggregate contribution. Local cumulative day/model snapshots can therefore be corrected safely, while null-key manual observations remain append-only.

`UnknownCostCount` counts only genuinely undescribed costs; a `CostBasis.None` event is a known zero ("no price applies") and is never counted as missing pricing data, and a positive cost under `None` is rejected as contradictory.

A manual cost correction (`PATCH /api/events/{eventKey}/cost`) rebases an estimated, notional or `None` event to `ProviderEstimated` — the figure is now provider-reported via the operator — and stamps `CorrectedAt`. The basis change removes the row from the repricing pass, and while the marker stands a replay carrying no cost of its own (the local sweepers re-post every snapshot with `costUsd: null` on every run) still updates usage figures but cannot roll the corrected cost back to unknown. A source post carrying an explicit cost re-asserts authority and clears the marker. A reprice that cannot resolve a quote never blanks an already-known cost: the event keeps its last known price and basis.

## Time, freshness, and currency

Occurrence/usage time says when consumption happened. `ObservedAt` says when Observatory obtained it. A provider or export update time may be later still. Source status separately records last attempt, last success, and latest source observation; none means the source has not supplied that fact.

Stored provider estimates, list-price estimates, and notional values use USD catalogs. Google Cloud Billing export starts in its native export currency and follows the existing historical FX path for GBP presentation. Tokens are counts. Missing tokens or money are `Not reported`, never zero.

## Pricing renewal and safety

Pricing refreshes daily and shortly after startup when the last successful refresh is over a day old. Fetched runtime inputs:

- [OpenAI pricing](https://developers.openai.com/api/docs/pricing.md)
- [Claude pricing](https://platform.claude.com/docs/en/about-claude/pricing.md)
- [Kimi documentation](https://platform.kimi.ai/docs/llms.txt)

The Gemini Developer API catalog is bundled rather than fetched: `gemini-developer-api-pricing` loads from the shipped catalog at startup and is unaffected by fetch outages.

The [Google Cloud Billing Catalog API](https://docs.cloud.google.com/billing/v1/how-tos/catalog-api) is the planned official authority, but is currently unfetched and unavailable: `GooglePricingSource.VerifiedMappings` is empty, so its source definition remains not configured during pricing checks.

Each provider parser is strict about its own shape. A valid snapshot retains raw evidence, content hash, retrieval time, source URL, and provider-declared or observed effective dates. Future-effective rows are stored before use; a changed valid snapshot activates atomically while earlier history remains. Identical snapshots are discarded. Bundled cold-start catalogs and the last known good snapshot survive an outage, timeout, malformed page, partial catalog, or changed page shape.

The network boundary accepts only fixed HTTPS allowlists, validates redirect hosts, limits response size and time, performs non-executable parsing, and stores sanitized errors. BenchLM is discovery/cross-check evidence only, never an authority or fallback.

Unknown models or required dimensions resolve to `null` with a warning; there is no generic fallback price. Repricing uses occurrence date and affects only eligible `ListPriceEstimate` and `Notional` observations with sufficient dimensions. It never rewrites `Billed`, `ProviderEstimated`, ambiguous legacy/unknown, or dimension-incomplete observations.

> [!IMPORTANT]
> `google-cloud-catalog` remains unavailable because exact Cloud SKU mappings are empty. This does not affect the separate bundled `gemini-developer-api-pricing` catalog used for explicitly identified Gemini API-key review sessions, or Google billed export.
